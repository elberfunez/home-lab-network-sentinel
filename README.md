# Home Lab Network Sentinel

A two-person learning project: build a Python tool that checks TCP ports on a Raspberry Pi, compares results with a baseline, makes an HTTP check, and saves a CSV report.

Start with [project_instructions.md](project_instructions.md).

## Working together
- Create a branch per change, open a pull request, and have the other person review it.
- Never commit passwords, keys, or generated reports.
